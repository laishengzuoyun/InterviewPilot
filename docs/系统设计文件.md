# 2. System Overview

InterviewPilot 是一个基于 Java Spring Boot 和 Vue3 的 AI 求职辅助平台。

系统支持用户上传简历、创建目标岗位、生成 AI 岗位匹配报告，并进行模拟面试训练。用户可以查看历史分析记录和面试反馈，从而提升求职准备效率。

本项目默认使用 **Mimo AI** 作为 AI 服务提供方。

为了避免系统与某一个具体 AI 平台强绑定，后端会设计统一的 **AI Provider Layer**。所有 AI 功能都通过统一接口调用，方便后期切换到其他模型服务。

---

# 3. System Goals

系统需要实现以下目标：

1. 提供用户注册、登录与身份认证功能。
2. 支持用户上传 PDF / DOCX 格式简历。
3. 支持从简历文件中提取文本内容。
4. 支持用户创建和管理目标岗位。
5. 支持 Mimo AI 分析简历与岗位之间的匹配程度。
6. 支持 Mimo AI 生成面试题并评价用户回答。
7. 支持历史记录查询。
8. 提供清晰、简洁、可演示的前端页面。
9. 支持本地运行与 Docker 部署。
10. 支持后续扩展其他 AI Provider。

# 7. Core Business Workflow

## 7.1 User Login Workflow

```text
User enters email and password
        ↓
Frontend sends login request
        ↓
Backend checks user information
        ↓
Password is verified
        ↓
JWT token is generated
        ↓
Frontend stores token
        ↓
User enters dashboard
```

---

## 7.2 Resume Upload Workflow

```text
User uploads PDF / DOCX
        ↓
Frontend sends file to backend
        ↓
Backend saves file locally
        ↓
Backend extracts text content
        ↓
Resume metadata and text are saved to MySQL
        ↓
Frontend displays resume list
```

---

## 7.3 AI Matching Workflow

```text
User selects resume and job
        ↓
Backend fetches resume text and job description
        ↓
Backend builds matching prompt
        ↓
AiService calls AiClient
        ↓
MimoAiClient sends request to Mimo AI
        ↓
Mimo AI returns analysis result
        ↓
Backend parses and stores report
        ↓
Frontend displays matching report
```

---

## 7.4 Mock Interview Workflow

```text
User selects resume and job
        ↓
Backend builds interview prompt
        ↓
AiService calls Mimo AI through AiClient
        ↓
Mimo AI generates interview questions
        ↓
User answers questions
        ↓
Mimo AI evaluates answers
        ↓
Backend stores interview record
        ↓
Frontend displays feedback
```

# 9. AI Service Design

## 9.1 Design Principle

AI 相关代码不应该直接写死在业务模块中。

错误示例：

```java
matchService.callMimoApi(prompt);
```

推荐设计：

```java
aiService.chat(prompt);
```

然后由 `AiService` 调用统一的 `AiClient` 接口。

---

## 9.2 AI Provider Interface

```java
public interface AiClient {
    String chat(String prompt);
}
```

---

## 9.3 Mimo AI Implementation

```java
@Component
public class MimoAiClient implements AiClient {

    private final AiProperties aiProperties;

    public MimoAiClient(AiProperties aiProperties) {
        this.aiProperties = aiProperties;
    }

    @Override
    public String chat(String prompt) {
        // Build HTTP request
        // Send request to Mimo AI
        // Return response content
        return null;
    }
}
```

---

## 9.4 AI Configuration

Recommended `application.yml`:


# 11. Database Design

## 11.1 ER Relationship

```text
User 1 ---- N Resume

User 1 ---- N Job

User 1 ---- N MatchReport

Resume 1 ---- N MatchReport

Job 1 ---- N MatchReport

User 1 ---- N InterviewSession

Resume 1 ---- N InterviewSession

Job 1 ---- N InterviewSession

InterviewSession 1 ---- N InterviewQuestion
```

---

## 11.2 Table: user

```sql
CREATE TABLE user (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

---

## 11.3 Table: resume

```sql
CREATE TABLE resume (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    file_name VARCHAR(255) NOT NULL,
    file_path VARCHAR(500) NOT NULL,
    content_text LONGTEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id)
);
```

---

## 11.4 Table: job

```sql
CREATE TABLE job (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    title VARCHAR(100) NOT NULL,
    company VARCHAR(100),
    description TEXT,
    requirements TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id)
);
```

---

## 11.5 Table: match_report

```sql
CREATE TABLE match_report (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    resume_id BIGINT NOT NULL,
    job_id BIGINT NOT NULL,
    score INT,
    strengths TEXT,
    weaknesses TEXT,
    suggestions TEXT,
    interview_preparation TEXT,
    raw_ai_result LONGTEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id),
    FOREIGN KEY (resume_id) REFERENCES resume(id),
    FOREIGN KEY (job_id) REFERENCES job(id)
);
```

---

## 11.6 Table: interview_session

```sql
CREATE TABLE interview_session (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    resume_id BIGINT NOT NULL,
    job_id BIGINT NOT NULL,
    overall_feedback TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES user(id),
    FOREIGN KEY (resume_id) REFERENCES resume(id),
    FOREIGN KEY (job_id) REFERENCES job(id)
);
```

---

## 11.7 Table: interview_question

```sql
CREATE TABLE interview_question (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id BIGINT NOT NULL,
    question TEXT NOT NULL,
    answer TEXT,
    feedback TEXT,
    improved_answer TEXT,
    score INT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (session_id) REFERENCES interview_session(id)
);
```

# 16. Security Design

## 16.1 Authentication

The system uses JWT-based authentication.

```text
User Login
    ↓
Backend verifies password
    ↓
Generate JWT
    ↓
Frontend stores JWT
    ↓
Frontend sends JWT in request header
```

Request header:

```http
Authorization: Bearer <token>
```

---

## 16.2 Password Security

Passwords must not be stored in plain text.

Use BCrypt to hash passwords before saving them into the database.

---

## 16.3 API Permission Control

Rules:

* `/api/auth/**` can be accessed without login.
* Other APIs require valid JWT.
* Users can only access their own resumes, jobs, reports, and interview records.

---

## 16.4 File Upload Security

The system should check:

* File type
* File size
* File extension
* MIME type

Allowed file types:

```text
.pdf
.docx
```

Recommended max file size:

```text
10MB
```

---

## 16.5 AI Key Security

Mimo AI API Key must not be hardcoded.

Correct storage:

```text
application.yml
environment variables
Docker secrets
```

Wrong storage:

```text
Java source code
frontend code
GitHub public repository
```
